# Panel administrativo

Next.js + Supabase. Guía: [fase 5](../../docs/fase-5-administracion.md).

Desde raíz: `npm run dev --prefix apps/admin`. Abre http://127.0.0.1:3001 .

Configura NEXT_PUBLIC_SUPABASE_URL y NEXT_PUBLIC_SUPABASE_ANON_KEY en .env.local; usa exclusivamente la clave pública. npm ci instala las versiones del lockfile.
